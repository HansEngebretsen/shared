<hans-footer>

A lightweight, self-contained web component footer.

Light Theme - Default Logo (logo="default")

Default look. Shows "he" logo, morphs to profile photo on hovering "hans".

Dark Theme - HE Logo Only (logo="he")

Shows the "he" logo only. No profile picture, and no hover transition.

Warm Sand Theme - Profile Pic Only (logo="profile")

Shows the profile picture only. Direct hover increases its opacity.

Cool Indigo Theme - No Logo (logo="none")

Displays only the text. The logo wrapper is completely hidden.

Static Color (text-color="#c2410c")

One static color used in both light and dark mode. Blending is disabled.

Static Light/Dark (text-color-light + text-color-dark)

Follows your OS color scheme — toggle light/dark to see it switch.
